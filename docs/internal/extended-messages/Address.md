### Address02 - NAMESERVER_IP_WITHOUT_REVERSE - WARNING

"Nameserver {nsname} has an IP address ({ns_ip}) without PTR configured."

Reverse records (PTR) is a way to indicate what an IP address is used for, by
mapping a name to it. Having a reverse record for the name servers IP address 
lends them legitimacy and it is recommended for name servers to have one. You 
can contact your name server operator about the issue.
