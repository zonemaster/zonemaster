# Release v2026.1.1 (2026-07-22)

### \[Release information\]
 - This release only contains a bug fix in Zonemaster-Backend. The bug can make tests crash. The recommendation is to update [Zonemaster-Backend] from the version in the previous release ([v2026.1]).

### \[Breaking changes\]
- None for this release

### \[Deprecations\]
- None for this release
